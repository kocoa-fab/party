팀원 실시간 공유 클라우드 설정

GitHub Pages는 정적 호스팅이므로, 팀원들이 각자 스마트폰에서 주문한 내용을 남들에게도 실시간으로 보이게 하고 영구 보존하려면 무료 실시간 클라우드 DB가 필요합니다.

💡 구글 Firebase로 1분 만에 연결하는 법 (무료):

  1. console.firebase.google.com 무료 접속 (구글 로그인)
  2. [프로젝트 추가] → 이름 입력 후 계속 완료
  3. 좌측 메뉴 [Realtime Database] → [데이터베이스 만들기] → [테스트 모드 시작] 완료
  4. 프로젝트 설정(⚙️) → 웹(</>) 앱 추가 → 나오는 firebaseConfig 복사

※ Firebase 웹 콘솔에서 제공된 코드 전체를 그대로 붙여넣으시면 자동 파싱됩니다.

💡 Supabase 테이블 안내:

SQL Editor에서 CREATE TABLE party_state (id text primary key, data jsonb, updated_at timestamp); 를 실행해야 합니다.

🌟 모든 팀원 자동 연결 팁 (추천):

GitHub 저장소의 index.html 파일 상단에 있는 DEFAULT_FIREBASE_CONFIG 변수에 설정값을 적어두면, 팀원 24명 전원이 아무런 설정 없이 링크만 열어도 자동으로 실시간 동기화됩니다!
